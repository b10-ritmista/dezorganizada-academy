# DezOrganizada Drums Academy

chat faça um aplicativo, onde o usuário vai fazer um cadastro/login, onde esse aplicativo referese a aulas de baterias da DezOrganizada Furiosa, onde vai ter video aulas para quer os novos membros consigam aprender com isso quero que faça umas etapas e com isso onde administradores vão subir as videos aulas, e com isso no final o usuário que está aprendendo vai ter um certificado para cada instrumentos que o uisuário escolheu para aprender, os instrumentos são caixa, tamborim, chocalho, repique, surdo, percussão, faça etapas de progresso para que o usuário final consigfa o certificado
